# 辟谣小助手（视频号 / 小程序视频真假提醒）

奶奶在微信里刷视频时——不管是**视频号**，还是**票圈、老友趣**这类小程序视频——屏幕边上会浮着一个大标签，一眼告诉她这个视频“能不能看”。视频可疑时，手机会用语音提醒；她想转发可疑视频时，会再劝她一次。

标签只说一句最关键的话，让老人一看就懂；点开卡片才是给家人看的详细原因。

| 标签（大字） | 颜色 | 意思 | 会不会说话（默认） |
| --- | --- | --- | --- |
| 🔍 正在看… | 灰 | 正在分析 | 不说 |
| ✅ 可以看 | 绿 | 娱乐、生活、正常新闻等，没发现问题 | 不说 |
| ❓ 先别信 | 黄 | 有具体说法，但查不到可靠来源 | 说 |
| ⚠️ 是假的 | 红 | 健康谣言、伪科学、编造的新闻或政策 | 说 |
| 🤖 AI假的 | 紫 | AI 生成、换脸、合成配音 | 说 |
| 🛑 别上当 | 橙红 | 卖保健品、诱导加微信、免费领等套路 | 说 |

点一下标签会展开详细说明；文字较多时可以在卡片里上下滑动看全，下面的“🔊 再说一遍”和“收起”按钮一直都在。卡片不会自动消失，看完点“收起”或点标签即可（换下一个视频会自动重置）。按住标签或卡片顶部的标题可以拖到别的位置。

> AI 的判断仅供参考，也会出错。这个软件故意不说“这是真的”，最多只说“可以看”。

## 工作原理

1. 无障碍服务盯着屏幕。微信视频号（界面名带 `finder`）、微信小程序视频（带 `appbrand`，如票圈/老友趣）会显示悬浮标签；开启“任何 App 里有视频在播就检测”后，抖音、快手、今日头条等及其它应用里**正在播放视频**时也会显示（静止的聊天/设置/桌面不动）。
2. 每换一个视频，先等 1.5 秒。如果她在 1.5 秒内就划走了，不分析，也不花钱。
3. 截两张屏（相隔 2.5 秒，截图里的悬浮标签会被涂黑），同时读取屏幕上的文字（作者、标题），一起发给看图模型。
4. 如果视频里有可以核实的说法（健康功效、新闻、政策补贴等），再用阿里云百炼的联网搜索核实一遍。核实没成功（比如余额不足、网络不好）时，沿用看图的结论。
5. 显示结论，可疑时语音播报。为了让老人在视频声音里也听得见，提醒声走手机的**闹钟声道**（和视频是两路、互不盖过），播报时把闹钟音量临时开到最大、说完自动调回。点“转发/分享”，或进入“选择聊天”页面时，可疑视频会再提醒一次。

同一个视频划回来时，直接用之前的结论，不重复花钱。

往下刷视频：**每刷到一条新视频都会重新识别**（标签随之更新）。防误触做了三件事：① 抖音/快手这类翻页列表里，**手滑一下又弹回来**（没真正翻页）不算新视频；② 评论框、弹出的提示这类**满屏文字**的页面不当成视频；③ **同一类提醒短时间内不重复用语音念**（标签照常更新，只是不反复出声）。另外，判成可疑时**只弹小标签+语音、不自动展开大卡片**——否则大卡片会盖住屏幕、让你划不动下一条；想看详细原因，点一下标签即可展开。

## 费用

默认模型是 `qwen3.7-flash`（输入 ¥0.2/百万 token，输出 ¥0.8/百万 token），联网搜索每千次 ¥3。

- 每个视频大约 ¥0.0007～¥0.005（0.07～0.5 分钱）
- 一天看 200 个视频，大约 ¥0.2～¥1
- 设置里有“每天最多分析几个视频”（默认 600），可以防止意外花钱太多

新开通百炼的账号，每个模型有 100 万 token 的免费额度；联网搜索没有免费额度。

## 隐私

- 只在视频号 / 小程序 / 正在播放视频的画面截图；聊天、设置、桌面等静止界面不截图。广义检测靠“有没有视频在播”判断，没视频在播就不看；通话/视频通话、支付（支付宝/云闪付）、系统界面、桌面会自动跳过。
- 截图和屏幕文字只发给你填写的 AI 服务，手机上不保存截图。
- API Key 只保存在这台手机上的应用私有存储里，不会被备份。

## 安装和设置（家人来操作）

需要安卓 11 或以上的手机。鸿蒙 NEXT（5.0 以上）和 iPhone 不能用。

### 1. 安装

把 `app/build/outputs/apk/debug/app-debug.apk` 发到奶奶手机上（微信文件传输助手、数据线都行），点开安装。手机提示“未知来源”或“风险应用”时，选择允许、继续安装。

### 2. 打开无障碍服务

打开“辟谣小助手”，点 **打开无障碍设置**，找到“辟谣小助手：视频号真假提醒”（有的手机在“已下载的应用”或“已安装的服务”里面），把开关打开。

开关是灰色的、打不开时（安卓 13 及以上的手机对自己装的应用有这个限制）：

1. 回到辟谣小助手，点 **打开本应用信息页**
2. 点右上角 ⋮，选 **允许受限制的设置**
3. 再回去打开无障碍开关

### 3. 防止被系统关掉

国产手机会自动关掉后台应用，关掉以后小标签就不出来了。点 **允许后台运行（忽略电池优化）**，然后按手机品牌设置。

> ⚠️ 注意：这些开关<strong>不在</strong>「应用信息 / 应用管理」里（很多人在那里找不到是正常的）。要去「电池」相关的菜单。实测 vivo（OriginOS 3）路径见下表；若按菜单找不到，直接在设置顶部<strong>搜索框搜「后台耗电」</strong>最快。

| 品牌 | 设置位置 |
| --- | --- |
| 小米 / 红米 | 应用信息 → 省电策略 → 无限制；应用信息 → 自启动 打开 |
| OPPO / 一加 / realme | 应用信息 → 耗电管理 → 允许后台运行、允许自启动 |
| 华为（鸿蒙 4.x 及以下）/ 荣耀 | 设置 → 电池 → 应用启动管理 → 辟谣小助手 → 改成手动管理，三个开关都打开 |
| vivo / iQOO | 设置 → 电池 → 后台耗电管理 → 辟谣小助手 → 允许后台高耗电（搜索「后台耗电」直达）。vivo 的「自启动」列表通常不收录这种自己装的应用，找不到属正常，不影响使用；只是重启手机后要再打开一次 App。 |

最后打开最近任务（多任务）界面，把辟谣小助手锁住（下拉卡片或点锁形图标）。

### 4. 语音

点 **试听语音**。没有声音时，看上面的状态：

- “语音引擎不支持中文”：点 **打开文字转语音设置**，把首选引擎换成支持中文的（手机自带的语音引擎、讯飞等都可以）。
- 提醒声用的是手机**闹钟声道**、播报时会自动开到最大，不受媒体音量影响（视频本身的音量不会被动）。

可以改称呼（默认“奶奶”），也可以选择“每个视频都说”或者“不说话，只在屏幕上显示”。

### 5. AI 服务

1. 用电脑或手机打开 [阿里云百炼控制台](https://bailian.console.aliyun.com/)，登录阿里云账号（没有就用手机号注册，或者用支付宝扫码登录），按提示完成实名认证，开通百炼服务
2. 右上角地域选 **华北2（北京）**，打开 [API Key 页面](https://bailian.console.aliyun.com/cn-beijing/model/settings/api-key)，点 **创建 API Key**。权限建议选“自定义”，可访问模型只勾 `qwen3.7-flash`（换了模型的话要一起勾上）。这样万一 Key 泄露，别人也只能调这个便宜模型。点复制图标，复制 `sk-` 开头的 Key
3. 在阿里云“费用”里充一点钱（比如 ¥10），再设一个余额预警。联网搜索没有免费额度，余额不足时会提示欠费
4. 把 Key 填到辟谣小助手的 **API Key** 里，点 **保存设置**
5. 点 **用一条示例谣言测试 AI**：会用一张假的“生鸡蛋降血压”截图走一遍完整流程，看到“测试成功”并听到语音提醒就说明配好了

阿里云不建议把长期有效的 Key 放在手机 App 里，所以请给奶奶手机单独建一个 Key，不要和别的用途共用；不用了就在 API Key 页面删掉。

接口地址默认是 `https://dashscope.aliyuncs.com/compatible-mode/v1`。百炼控制台里给的“业务空间专属域名”（形如 `https://llm-xxx.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`）也可以填进去，速度更稳定。

想判断得更准，可以把两个模型都换成 `qwen3.7-plus`（大约贵 8 倍），或者打开“深度思考”（更慢）。也可以用别家兼容 OpenAI 接口的服务（看图模型必须能看图片），但“上网核实”只支持阿里云百炼。

### 6. 试一下

打开微信 → 发现 → 视频号，左边出现“🔍 正在看…”，几秒后变成结论，就说明一切正常。打开票圈等小程序视频也一样会出现标签，划到下一个视频会自动重新判断。

## 出问题时

辟谣小助手首页最下面的“运行情况”会显示：服务是否在运行、今天分析了几个视频、最近看到的微信界面、最近的结论和错误。

- **打开视频号后不出现小标签**：先确认“服务在运行：是”。再看“最近的微信界面”，如果打开视频号时显示的名字里没有 `finder`（微信改版了），把视频号界面名里有代表性的一段填到“高级 → 视频号界面关键词”里。
- **别的 App（抖音/快手等）或小程序里不出现标签**：确认“高级”里“任何App里有视频在播就检测”“也盯着小程序里的视频”都勾着；视频要真的在**播放**（暂停时可能先不显示）。刚开服务时若已停在某视频上，退出去重进一次即可。
- **标签显示“暂时看不了”**：展开标签看原因。常见原因：Key 填错（401）、账户欠费、网络不好。
- **截图失败**：个别手机系统或者微信页面不允许截图，这时候只用屏幕文字判断。
- **运行情况里出现“上网核实失败”**：联网搜索没成功，这个视频只用了看图的结论。常见原因：余额不足、核实模型不支持联网搜索、网络不好。

## 已知限制

- AI 会判断错，特别是刚出来的谣言、没有字幕的视频（这个软件不听声音，只看画面和屏幕上的字）。
- 判断要 5～15 秒，划得很快时来不及显示结论。
- 视频号 / 小程序页面是靠微信内部的界面名（含 `finder` / `appbrand`）认出来的，转发按钮是靠“转发 / 分享 / 发给好友”这几个字认出来的。微信改版后可能失效；视频号界面名可以在“高级”里改，转发提醒要改代码。已在 vivo S10（OriginOS 3 / 安卓 13）+ 微信 8.0.77 上实测：视频号页面名是 `com.tencent.mm/.plugin.finder.ui.FinderHomeAffinityUI`（含 `finder`），小程序视频页面名是 `com.tencent.mm/.plugin.appbrand.ui.AppBrandUI00`（含 `appbrand`）；票圈、老友趣可识别、逐条判断，底部“分享到群 / 发给好友”也能触发转发提醒。
- 覆盖：微信视频号 + 任意微信小程序视频（票圈/老友趣等）+ 抖音/快手/好看/西瓜/今日头条/B站/腾讯视频/爱奇艺/优酷/芒果TV 等常见视频 App +“任何 App 里正在播放的视频”。转发拦截只在微信里有；独立 App 只做提醒。已在 vivo S10 实测抖音可识别并逐条判断（进入即判、每划一条自动重判）。

## vivo / OriginOS 注意事项（实测，已解决）

在 vivo S10（OriginOS 3、安卓 13、微信 8.0.77）上实测。两个曾经的拦路问题现在都解决了：

### 1. 一打开微信，服务被 vivo 关掉 —— 已用自愈看门狗解决

现象：vivo 系统安全组件 `com.vivo.safecenter`（i管家）会在特定时机把第三方无障碍服务从系统设置里删掉（实测相隔 45 毫秒）。它只是<strong>清空设置</strong>，并不杀 App 进程。

解决：新增一个前台服务 `WatchdogService`，用 `ContentObserver` 盯着 `enabled_accessibility_services`，一旦发现自己被移除就立刻写回去。实测从被移除到恢复约 <strong>360 毫秒</strong>（日志：`service stopped` → 361ms 后 `service connected`），几乎无感。写系统设置需要 `WRITE_SECURE_SETTINGS` 权限，用电脑 adb 授权一次即可（见下）。

补充实测：这个关闭是“边沿触发”的——只在应用切到前台那一下发生，不是持续的（服务一旦开着就一直在，不会被反复关）。而且在本机后来变得不再触发（多半是因为之前用手指在系统设置里点过「允许」，被 safecenter 认作可信）。即便如此，看门狗作为保险始终在跑；用“清空设置”模拟 safecenter 的完全相同操作，已验证能稳定恢复。

### 2. 无线调试老掉线 —— 已找到真正原因并解决

现象：adb 无线调试频繁断开，手机 IP 还会变（实测 .15 → .17）。之前误以为是锁屏/全屏视频/安全弹窗导致，其实不是。

真正原因：这台手机<strong>同时存了两个 Wi-Fi：一个常用的加密网络，和一个开放网络</strong>，系统开着“自动连接开放网络”，于是在两个网络之间来回切（`dumpsys wifi` 的连接历史里全是 `ROAM_UNRELATED`）。每切一次，TCP/adb 连接就断，加上 MAC 随机化导致重新拿到的 IP 变了。

解决：`settings put global wifi_wakeup_enabled 0`（关掉自动连开放网络）+ `cmd wifi forget-network <id>`（删掉那个开放网络）。之后用经典 `adb tcpip 5555`（比安卓 11 的无线调试稳，锁屏不断、不依赖配对）。实测连续 2 分钟稳定：期间锁屏约 40 秒、把微信切到前台，PC 侧 40 次轮询全部在线，手机端 SSID 一直是常用网络、IP 不变，无切换无掉线。

### 其它实测结论

- 识别、截图、AI 判断、语音在真机上都正常。实测在真实视频号里连续判断多个视频：AI 短剧/AI 宝宝视频 → 🤖，益智游戏 → ✅，约 2.5～3 秒出结论并按设置播报，悬浮标签正常显示。小程序视频（票圈、老友趣）同样实测通过：进入即判断、每划一条自动重判，AI 剧情 → 🤖「AI假的」、抗战科普/生活视频 → ✅「可以看」，播报与转发提醒都正常。
- 视频号页面读不到屏幕文字（日志里 `texts=0`），所以“划回看过的视频不重复判断”的缓存不起作用，AI 只能看截图。实测光看截图也能读出画面上的“含AI生成内容”等字样。小程序视频同样读不到文字、也拿不到滚动序号，所以每次划动都按“新视频”重新判断（不走缓存）。
- 无障碍第一次仍建议用手指在系统设置里开（弹出的“允许”是带倒计时的安全窗口，只能手点）。开过一次之后，看门狗负责保持它开着。
- 调试完记得关掉开发者选项（vivo 会把“USB 调试开启”算作支付风险）。

### 给 vivo（及类似国产 ROM）装机：授权看门狗

用数据线连电脑，执行一次（卸载重装后需重新执行；系统更新一般不用）：

```bat
adb shell pm grant com.grandma.rumorguard android.permission.WRITE_SECURE_SETTINGS
```

授权后，打开一次“辟谣小助手”让看门狗启动；首页“运行情况”里“保护（防系统关闭）”会显示“已开启”。没授权也能用，只是被系统关掉后不会自动恢复（显示“待电脑授权一次”）。

## 编译

需要 JDK 17 或以上，以及 Android SDK（compileSdk 36、build-tools 36）。在 `local.properties` 里写好 `sdk.dir`，然后：

```bat
gradlew.bat testDebugUnitTest assembleDebug
```

APK 生成在 `app/build/outputs/apk/debug/app-debug.apk`。这是调试签名的包，签名用的是这台电脑上的 `%USERPROFILE%\.android\debug.keystore`。以后要覆盖安装新版本，必须在同一台电脑上编译，否则要先在手机上卸载旧版（卸载后要重新开无障碍、重新填 Key）。

## 代码结构

| 文件 | 作用 |
| --- | --- |
| `GuardService.kt` | 无障碍服务：识别视频号、判断是不是换了视频、截图、转发提醒 |
| `Overlay.kt` | 悬浮标签和展开卡片（无障碍悬浮层，不需要悬浮窗权限） |
| `FactCheck.kt` / `Prompts.kt` | 两步判断：看图 → 联网核实（核实失败沿用看图的结论）；提示词 |
| `Analyzer.kt` | 在后台线程跑判断，换视频时取消上一次 |
| `ChatCall.kt` | OpenAI 兼容接口的流式调用 |
| `VerdictParser.kt` | 解析 AI 回复，容忍代码块、多余文字和不规范的 JSON |
| `Speaker.kt` | 中文语音播报：走闹钟声道、把闹钟音量开到最大盖过视频（不改动视频/媒体音量） |
| `ScreenText.kt` / `ImageEncoder.kt` | 读屏幕文字、压缩截图 |
| `MainActivity.kt` | 设置页面、AI 测试、运行情况 |
| `WatchdogService.kt` / `AccessibilityGuard.kt` | 前台看门狗：被系统关掉后自动把无障碍服务重新打开（需 `WRITE_SECURE_SETTINGS`） |
| `BootReceiver.kt` | 开机后自动拉起看门狗 |
